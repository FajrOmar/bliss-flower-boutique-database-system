IS220,IS221_ Bliss Flower Boutique Database System

Overview:

Bliss Flower Boutique Database System is a university project developed across two consecutive courses: **Database Fundamentals** and **Database Administration**.

The project evolved from designing a relational database into a fully functional database management system that supports data storage, database programming, user and role management, performance optimization, and reporting.

----

Objectives:

- Design a normalized relational database.
- Build a complete database for a flower boutique.
- Implement SQL scripts for database creation and management.
- Apply database administration concepts.
- Manage users, roles, and permissions.
- Improve database performance using optimization techniques.
